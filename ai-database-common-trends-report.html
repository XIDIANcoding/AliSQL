一、核心结论

共同趋势不是简单的“自然语言 + Agent + 知识图谱”，而是围绕企业既有数据，统一事务、分析、全文、向量、模型计算、语义治理和 Agent 访问。

关系数据库厂商从 TP 内核向 AP、向量、AI Function 和开放湖扩展；数仓和湖仓厂商从 AP/湖数据向 OLTP、实时服务和 Agent 状态管理扩展。两条路线最终汇聚到统一、开放、可治理的企业 AI 数据底座。

知识图谱是金融风险、供应链、设备拓扑等关系密集场景的高价值能力，但不是所有客户的基础配置。更普遍的共同能力是 HTAP、混合检索、企业 RAG、自然语言分析、Agent 和统一治理。
