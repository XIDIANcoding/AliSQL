腾讯云 ChatBI 测试数据包

可导入 CSV 样例表 · 需创建的知识库清单 · 能体现知识库价值的测试用例（对照官方：数据表知识 / 计算字段 / 习惯知识 / 事件知识）

0. 格式说明

ChatBI / 腾讯云 BI 导入数据表支持的是 CSV / Excel 等表格格式，不是 SVG（矢量图）。本包提供的是 UTF-8 BOM 的 CSV，可直接在腾讯云 BI 中「创建数据表 → 本地上传 / 导入」。若你确实需要 SVG 图表素材，与「导入数据表」无关，可另说。

文件目录：chatbi-tencent-testset/

  • dws_retail_trade_di.csv — 主宽表（约 5800+ 行，2023-01-01～2024-12-31 日粒度抽样），建议作为 ChatBI 主问数表
  • dim_customer.csv — 客户维表（可选，测智能选多表）
  • dim_region.csv — 地区维表（可选）
  • README-知识库与测试用例.html — 本说明（即当前页）

1. 导入前：表与字段怎么配（影响智能选表 / 澄清）

1.1 主表建议配置

配置项建议值原因（官方能力）
数据表名称零售交易日汇总表智能选表依赖表名语义
表备注主表 / 日汇总 / 主题：零售订单成交与毛利；含大区、省份、品类、渠道、客户官方「选表效果提升：表类型+主题」
读取数据模式读取表头和内容自动生成字符型枚举知识（品类/渠道/省份等），澄清与值映射更准
读取字段全选字符型：大区、省份、商品品类、销售渠道、客户名称、是否退货值→字段索引
对话示例提问见下文「引导语」3 条降低冷启动提问成本

1.2 主表字段一览

字段名类型建议字段备注建议
订单ID文本订单唯一编号
订单日期日期/时间下单成交日期；分析时间主字段
大区文本华东/华北/华南/西南/华中
省份文本收货/销售省份
商品品类文本进口商品、出口商品、自有品牌、联名款
销售渠道文本天猫旗舰店、京东自营、抖音小店、线下门店、企微私域
客户名称文本成交客户名称
销售额数值实际支付成交额 GMV；同义词：流水、营收、成交额

2. 需要创建哪些知识库（按腾讯官方四类）

对照官方手册：数据表启用时的表结构知识 + 计算字段知识库、习惯知识库（时间类/非时间类）、事件知识库（仅波动归因）。建议按下面清单逐条录入并启用。

2.1 数据表知识（启用表时自动生成，需人工补备注）

项操作
表名 / 表备注 / 字段备注按上一节填写；这是智能选表与选字段的基础
读取模式选「读取表头和内容」，让「进口商品」「天猫旗舰店」等值进入知识库

2.2 计算字段知识库 必建

知识名称推荐录入内容（按官方模板风格）证明什么
毛利率临时计算字段：毛利率 = 毛利 / 销售额；当用户问毛利率、毛利率情况、毛利占比时使用该计算逻辑 表中无毛利率列时仍能正确计算
客单价临时计算字段：客单价 = 销售额 / 订单量 复合指标需知识库，不能靠模型瞎编分母

2.3 习惯知识库 · 非时间类 必建

知识名称推荐录入内容证明什么
收入口径当用户说「收入」「营收」「流水」「成交额」「GMV」时，统一映射为字段「销售额」进行求和 口语≠字段名，无知识易选错列或拒答
我们/公司主体用户说「我们」「公司」「集团」时，默认分析本表全部数据，不追问主体；若提到具体客户名称则按客户名称过滤 减少「主体不清晰」追问
退货口径问销售额/收入时默认只统计「是否退货=否」的订单；若用户明确说含退货则不过滤 业务默认规则，非表结构能表达

2.4 习惯知识库 · 时间类 必建

官方说明：时间类习惯知识需在「配置 → 数据表」中关闭时间追问后才会按知识生效。测试时注意开关。
知识名称推荐录入内容证明什么
默认时间范围用户未指定时间时，默认查询「订单日期」为2024年（或「最近完整自然月」——按你测试当天改成固定 2024 年便于复现） 关掉追问后，模糊问「收入怎么样」仍能出数
今年/去年「今年」=2024年；「去年」=2023年（与样例数据年份对齐） 相对时间词稳定落地

2.5 事件知识库 测波动归因时必建

知识名称推荐录入内容证明什么
2024年618大促2024-06-15 至 2024-06-20 为公司「618大促」活动期，投放与满减力度加大，销售额通常显著高于日常 归因总结能引用业务事件，而不仅是维度贡献数字
2024年双十一2024-11-10 至 2024-11-12 为「双十一」大促，天猫与抖音渠道为主力 同上，渠道波动可被事件解释
官方建议单表事件知识不宜过多（<30 条）；本测试 2 条足够。

2.6 引导语（表级示例提问）

  1. 2024年各大区的销售额分别是多少
  2. 去年进口商品的毛利率是多少
  3. 对比2023年和2024年销售额波动情况

3. 测试用例（体现知识库价值）

建议：每条用例先关闭对应知识问一遍，再启用知识问一遍，对比差异。下表「预期（有知识）」即知识库价值体现点。

3.1 计算字段知识库

#提问无知识时常见表现有知识时预期
C1 2024年整体毛利率是多少？ 找不到字段 / 胡乱用毛利当毛利率 / 拒答 按 毛利÷销售额 计算并出图；展开推理可见计算逻辑
C2 2024年各商品品类的毛利率对比 仅出毛利绝对值或失败 按品类分组的毛利率柱图/表
C3 去年天猫旗舰店的客单价 无客单价字段则失败 销售额÷订单量，渠道=天猫旗舰店，时间=2023

3.2 习惯知识库 · 口径映射

#提问无知识时常见表现有知识时预期
H1 2024年我们收入怎么样？ 追问「收入指哪个字段」或选错字段；或追问主体 映射销售额；主体默认全表；结合时间类知识不乱追问
H2 看看GMV最高的前5个客户 不认 GMV 按客户名称汇总销售额 Top5（对照腾讯 DSL demo 场景）
H3 2024年流水按渠道拆开 「流水」无法映射 销售额 × 销售渠道分组
H4 2024年销售额（验证退货口径） 含退货订单，口径偏大 默认是否退货=否；可追问「含退货呢」做对比

3.3 习惯知识库 · 时间类（需关闭时间追问）

#提问关闭知识+开启追问启用时间知识+关闭追问
T1 收入怎么样？ 智能追问补时间 直接按默认2024年出销售额结果（体现习惯知识）
T2 去年华南大区收入 可能再追问「去年」指哪年 稳定落到2023年 + 大区=华南 + 销售额

3.4 内容值知识（读取表头和内容）

#提问仅读表头时读取表头和内容时
V1 进口商品卖得怎么样（2024） 需用户写清「商品品类为进口商品…」 自动识别「进口商品」属于商品品类枚举并过滤
V2 抖音小店2024年销售额 可能选错字段或追问 命中销售渠道枚举值

3.5 事件知识库 + 波动归因

前置：开启智能工具「波动归因」；录入 618 / 双十一事件知识。

#提问无事件知识有事件知识
E1 对比2023年和2024年销售额波动情况，并做归因 只有维度贡献（大区/渠道/品类）数字拆解 总结中能结合「618/双十一」等事件解释波动（官方：事件知识仅归因模块生效）
E2 2024年6月相对2023年6月销售额为什么变化？ 纯统计归因 总结可点出618大促时间窗

3.6 多轮对话（Session，非知识库但建议顺测）

#对话轮次预期
M1 ① 2024年华东销售额　② 那浙江呢？　③ 按月拆开 继承指标=销售额、时间=2024；②过滤省份=浙江；③按订单日期月粒度

3.7 智能选表（可选：同时启用主表+维表）

#配置提问预期
S1 智能选单表 + 仅主宽表 2024年各品类销售额 选中「零售交易日汇总表」
S2 智能选多表 + 主表与 dim_customer A级客户2024年销售额合计 关联客户维表按客户等级过滤（需字段能关联：客户名称）

4. 推荐测试顺序（30～60 分钟）

  1. 导入 dws_retail_trade_di.csv，配表名/备注/字段备注，启用并「读取表头和内容」
  2. 先不建知识库，跑 H1、C1、T1，记录失败/追问现象
  3. 录入计算字段 + 习惯知识（非时间），重跑 C1/C2、H1/H2，对比
  4. 关闭时间追问 + 录入时间类习惯，重跑 T1
  5. 开启波动归因 + 事件知识，跑 E1
  6. （可选）导入维表，测 S2；跑多轮 M1
验收标准：有知识后，C1/H1/T1/E1 四条必须明显优于无知识；展开推理中应能看到映射到「销售额」或毛利率计算公式。
