一、整体组件交互图（按部署位置分层）

连线上的数字编号对应下方「连接关系图例」；实线为主查询链路，虚线为反馈/回传链路。每层标题右侧标注部署位置。

1用户在各端输入自然语言提问，进入多轮对话模块
2基于历史语义补全后的完整提问，送入意图分类模块
3缺少时间或主体的模糊问题进入意图澄清模块
4澄清选项按钮回传用户点选（选项必定来自知识库真实字段）
5意图明确后进入智能选表（单表 / 多表关联决策）
6选表结果进入生成通道（简单查询走 Text2SQL，复杂计算走 Text2DSL）
7四个 Agent 的输出交由 DSL 整合模块合并、后处理与正确性验证
8Agent 层各阶段（分类 / 澄清精排 / 选表 / 生成 / 解读）通过 Prompt + ICL 调用大模型层
9知识库召回注入：ES 分词粗排候选、计算字段口径、习惯知识、Few-Shot 样例
10生成结果（SQL 或 DSL JSON）下发 BI 引擎层的查询编译器
11编译后的物理 SQL（复杂计算可能是多条）下发用户数据库执行
12查询结果返回 BI 引擎（权限过滤 · 结果缓存，供图表切换不重算）
13智能工具将统计算法结果 + 事件知识交给大模型生成归因总结与数据解读（虚线）
14图表 + SQL 白盒 + 结论渲染回应用层，支持二次交互
15点赞点踩反馈沉淀为 ICL Few-Shot 样本库（数据飞轮，虚线）
